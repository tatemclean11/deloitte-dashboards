What is it?

Claude Code is Claude Chat
with superpowers

In Claude.ai chat, Claude can only see what you paste into the conversation. Claude Code runs in your terminal and can directly read your files, edit code, and run commands — no copy-pasting needed.

Claude Chat
💬 You paste code in manually
👁️ Sees only what you show it
📋 Gives you text to copy
🔁 You apply changes yourself
🌐 Lives in the browser
Claude Code
📁 Reads your files directly
🗂️ Understands your whole project
✏️ Edits files for you
⚡ Runs commands in your terminal
💻 Lives in your terminal / IDE
The mental model

Think of it as
a pair programmer

Claude Code doesn't just answer questions — it takes action. When you ask it to "fix the bug in main.py," it actually opens the file, finds the bug, and rewrites the line.

You
There's a bug in my login function. Can you fix it?
Claude Code
Let me take a look...
📖 Reading auth/login.py ✏️ Editing line 42 — fixing null check ▶️ Running tests to confirm fix
Done! The bug was a missing None check before calling .lower(). All 12 tests pass.
Getting started

Installation in
3 steps

You'll need Node.js installed (version 18 or higher). Then it's just one command.

1

Install Claude Code globally

Open your terminal and run: npm install -g @anthropic-ai/claude-code

2

Navigate to your project folder

Use cd my-project to move into the folder you want to work on. Claude Code will read files from here.

3

Start a session

Type claude and press Enter. You'll be prompted to log in with your Anthropic account on first run.

💡 Prefer a desktop app? Claude Code also has a Mac/Windows desktop app at claude.ai/code that doesn't require the terminal setup.

Safety & control

Claude asks before
doing risky things

Claude Code won't silently delete files or run unknown commands. It asks for your permission first — you're always in control.

✅

Does automatically

Reading files, searching the codebase, explaining code, drafting changes for your review.

🛑

Asks you first

Writing or deleting files, running shell commands, installing packages, making git commits.

Pro tips

Handy
slash commands

Just like in Claude Chat, you can use /commands to trigger special behaviors.

💬

/clear — Start fresh

Clears the conversation history. Useful when switching to a completely different task so Claude isn't confused by old context.

🧠

/memory — Teach Claude about your project

Saves permanent notes about your project that Claude reads every session. Great for "always use TypeScript" or "our API base URL is X".

📋

/review — Code review

Asks Claude to review recent code changes (like a git diff) and flag potential issues, just like a teammate would.

❓

/help — See all commands

Lists every available command and what it does. Your cheat sheet.

Writing good prompts

Same rules as chat,
one extra tip

Your Claude Chat skills transfer directly. The one new habit: point Claude at specific files when you know which one is relevant.

❌ Vague

"Fix the login bug"

Claude has to guess which file, which bug, and what "fix" means.

✅ Specific

"In src/auth/login.js, the validateEmail() function doesn't catch empty strings. Fix it."

❌ Too big at once

"Build me a whole user authentication system"

Hard to review, easy to go wrong.

✅ Incremental

"Start by creating a login() function that takes email + password. We'll add registration next."

Where to use it

Works in your
favorite editor

Claude Code isn't just for the terminal — it integrates directly into VS Code and JetBrains IDEs.

💻

Terminal

Run claude anywhere. Works in any project, any language.

🔵

VS Code

Install the extension to get Claude Code in a sidebar panel without leaving your editor.

🟠

JetBrains

IntelliJ, WebStorm, PyCharm — all supported via the JetBrains Marketplace plugin.

Tip: In VS Code, open the Claude Code sidebar with the command palette (Ctrl+Shift+P) → "Open Claude Code". You'll see your conversation right next to your code.

🖥️ Desktop app available at claude.ai/code for Mac and Windows — no terminal setup required.
