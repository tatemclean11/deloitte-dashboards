How to add a dashboard

1. Drop your new .html file into the deloitte-dashboards folder.
2. Open this index.html file in a text editor, find the EXAMPLE CARD comment, copy the card block, and fill in your filename, title, and description.
3. Update the dashboard count badge near the top.
4. Commit and push both files via GitHub Desktop — your new dashboard will appear here within a minute.
